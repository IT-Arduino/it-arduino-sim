# IT-Arduino Симулятор

Симулятор Arduino в браузере для образовательного сайта
[it-arduino.ru](https://it-arduino.ru). Собрать схему, написать скетч,
скомпилировать и запустить — без единой детали на столе.

Работает на [sim.it-arduino.ru](https://sim.it-arduino.ru).

## Это форк

Основан на открытом симуляторе **Velxio** —
[davidmonterocrespo24/velxio](https://github.com/davidmonterocrespo24/velxio),
коммит `add3727a` от 2026-08-28. Форк создан 2026-08-28 и распространяется по
**AGPLv3**.

Что именно изменено и почему — в [FORK.md](FORK.md). Этот файл ведётся как
требование AGPLv3 §5(a): помечать изменённые файлы и указывать дату.

Апстрим подключён только на чтение. Форк ничего ему не отправляет — ни push,
ни pull request; как это устроено, описано в FORK.md, раздел «Обратного пути
нет».

## Что умеет

- **Четыре платы:** Arduino Uno, Nano, Mega, ATtiny85. Все — AVR.
- **Настоящая компиляция** через `arduino-cli`, с установкой библиотек из
  реестра Arduino.
- **Симуляция на уровне тактов** ядром avr8js: выводы, таймеры, прерывания,
  ШИМ, I2C, SPI, UART.
- **Аналоговая схемотехника** — SPICE-решатель для пассивных цепей.
- **Приборы:** монитор последовательного порта, осциллограф, логический
  анализатор.
- **157 готовых примеров** и каталог деталей: датчики, дисплеи, двигатели,
  логические микросхемы, операционные усилители.
- **Интерфейс на русском.**

Каталог деталей настраивается файлом
`frontend/public/components-config.json` без пересборки образа — инструкция в
[COMPONENTS.ru.md](COMPONENTS.ru.md).

## Чего нет

Апстрим умеет заметно больше, и это стоит назвать прямо: из форка **вырезано**
всё, что не нужно школьному курсу Arduino.

Нет ESP32 и ESP8266, Raspberry Pi и Pico, STM32, RISC-V, MicroPython,
эмуляции через QEMU, настольного приложения и облачных возможностей
velxio.dev. Кому нужно это — вам к апстриму, там всё на месте.

Побочный результат: образ **614 МБ** вместо **4.34 ГБ** у апстрима, и он
собирается из чистого клона без лицензионных ключей. Замеры и оговорки к ним —
в FORK.md.

## Запуск

Нужен Docker.

```bash
docker compose -f docker-compose.avr.yml up -d --build
```

Откроется на `http://localhost:3080`.

Первый запуск занимает несколько минут: контейнер скачивает ядра
`arduino:avr` и `ATTinyCore:avr`. Они остаются в томе, поэтому следующие
запуски — секунды.

Использовать нужно именно `docker-compose.avr.yml`. Апстримовский
`docker-compose.yml` собирает `Dockerfile.standalone`, а тому для стадии QEMU
требуется лицензионный ключ velxio.dev.
